# Inverse Problems in Mechanisms

Companion scripts for *Inverse Problems in Mechanisms: Linkages, Cams, and Gears* by Rómulo Sandoval Flórez, Claudia Patricia Parra Medina, and Germán Leandro Vargas Fonseca. The examples cover Chapters 3–7.

## Set up the environment

Use 64-bit Python 3.12, Git 2.34 or later, and, for Chapters 5 and 7, a C++ compiler targeting the same architecture as Python. The pinned Python environment was tested on Windows x64. Clone the version cited in the book and run the setup commands from its root.

```text
git clone --branch v1.0.0 https://github.com/romusan/inverse-problems-in-mechanisms-examples.git
cd inverse-problems-in-mechanisms-examples
```

**Windows PowerShell**

```powershell
python -m venv .venv
$py = ".\.venv\Scripts\python.exe"
& $py -m pip install -r requirements.txt
& $py -c "from pathlib import Path; Path('figures').mkdir(exist_ok=True)"
```

**Linux or macOS**

```sh
python3.12 -m venv .venv
py=.venv/bin/python
"$py" -m pip install -r requirements.txt
mkdir -p figures
```

Use this virtual environment's Python for the remaining commands. The blocks below use `python` to mean that interpreter. In PowerShell, replace `python` with `& $py`. In Linux or macOS, replace it with `"$py"`.

## Chapter 3 — Four-bar linkage

This example runs with the Python environment alone.

```text
python chapters/linkages/examples/fourbar_synthesis.py
```

The direct calculation solves both assembly positions at 60°, calculates the angular rates and accelerations on the positive branch, and checks the rocker-joint derivatives by centered differences. The inverse calculation fits the synthetic fixed-fixture target by differential evolution and local least squares, then checks closure and transmission over the full cycle. The refined fit has an RMS error of approximately 0.1476 mm. The script writes `fourbar-direct-example.pdf` and `fourbar-synthesis-example.pdf` to `figures/`.

### Build the C++ evaluator for Chapters 5 and 7

Use a native C++ compiler and the fetched source. On Windows, the example below uses the 64-bit MinGW-w64 compiler from MSYS2 UCRT64. Install the compiler by running `pacman -S mingw-w64-ucrt-x86_64-gcc` in the MSYS2 UCRT64 shell, then run the build below in PowerShell. Substitute the path to your MSYS2 installation if needed.

```powershell
$cam = "inputs/paper_BL_TASS_CAM/revision_campaign"
$compilerBin = "C:\msys64\ucrt64\bin"
$env:Path = "$compilerBin;$env:Path"
New-Item -ItemType Directory -Force "$cam/build" | Out-Null
& "$compilerBin\g++.exe" -std=c++17 -O3 -shared -static "$cam/cpp/cam_objective.cpp" -o "$cam/build/cam_objective.dll"
```

On Linux, build the shared object with the system compiler.

```sh
cam=inputs/paper_BL_TASS_CAM/revision_campaign
mkdir -p "$cam/build"
c++ -std=c++17 -O3 -shared -fPIC "$cam/cpp/cam_objective.cpp" -o "$cam/build/libcam_objective.so"
```

On macOS, build the dynamic library with the system compiler.

```sh
cam=inputs/paper_BL_TASS_CAM/revision_campaign
mkdir -p "$cam/build"
c++ -std=c++17 -O3 -dynamiclib "$cam/cpp/cam_objective.cpp" -o "$cam/build/libcam_objective.dylib"
```

The cam script prints the SHA-256 of the shared library it loads. Builds made with different compilers or flags can have different hashes. The script checks numerical agreement against the archived records.

## Run Chapters 4–7

```text
python chapters/linkages/examples/fef_graph_comparison.py --revision inputs/FEF-Graph/envio_Applied_Sciences/revision_2026
python chapters/cams/examples/periodic_cam_example.py --project inputs/paper_BL_TASS_CAM
python chapters/gears/examples/spur_gear_microgeometry.py --source inputs/gears_inversion/deposit_v6/gear_inverse_identifiability/src
python chapters/integration/examples/design_selection.py --research inputs
```

| Chapter | Results to check |
| --- | --- |
| 4 — Path synthesis | Recomputes the aggregate counts and rechecks the closure and transmission of archived designs. For CD-G at 20,000 calls and compact bounds, expect 21 accuracy-and-cycle successes out of 30 and no transmission-screen successes. Writes `figures/fef-graph-cycle-comparison.pdf`. |
| 5 — Flexible cam follower | Re-evaluates the archived controls with the periodic C++ solver. At 100 rad/s, expect about 2.685 mm RMS and 3.956 mm peak tracking error for the selected design. Checks the 21 speed evaluations and writes `figures/cam-periodic-inverse-example.pdf`. |
| 6 — Spur gears | Fits the flat transmission-error target, checks the fitted profiles on shifted phases at two torques, and solves the paired synthetic inversions. At 300 N·m on the shifted grid, expect about 1.214 µm RMS for the combined-relief profile. Writes `figures/spur-gear-microgeometry-example.pdf`. |
| 7 — Verification and design selection | Prints the linkage, cam, and gear scenario tables. The archived cam trials give 73 exceedances of 10 mm out of 1,000. The combined gear design's maximum requirement ratio is approximately 0.678. |

The Chapter 4 and 5 examples recheck designs selected in the published research campaigns. Chapter 7 also reuses archived cam trials. These runs reproduce the book's numerical examples and verification checks.
